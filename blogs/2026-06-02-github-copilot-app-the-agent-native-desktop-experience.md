GitHub unveiled new tools at Microsoft Build 2026 to support agentic development workflows, including the Copilot app with a "My Work" control center, canvas surfaces for inspectable work, cloud and local sandboxes, and enhanced code review capabilities. The announcement also includes expansion of the Copilot SDK across multiple programming languages, reinforcing GitHub's push toward agent-native developer tooling.
